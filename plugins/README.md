# plugins

> **File version:** 1.9.0 · **Last edit:** 2026-10-09 08:20 UTC

Built mod DLLs, ready to download one at a time.
Put a DLL in `<game folder>/BepInEx/plugins/IFZ-Compilation/`. See [docs/INSTALL.md](../docs/INSTALL.md).

File names: `IFZ-<modName>-v<MAJOR>.<MINOR>.<PATCH>.dll`. Only the newest version of each mod is kept here.

| DLL | Mod |
|-----|-----|
| `IFZ-productionPlanner-v0.8.0.dll` | Production Planner |
| `IFZ-modMenu-v0.1.0.dll` | Mod Menu |
